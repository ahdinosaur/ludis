# Concepts

The core ideas behind lusid:

- **[Plans](./plans.md)** — a `.lusid` file's structure: metadata, params, the `setup` function.
- **[Resources](./resources.md)** — declarative desired state. The `@resource/*` namespace.
- **[Operations](./operations.md)** — imperative actions. The `@operation/*` namespace.
- **[Dependencies](./dependencies.md)** — `requires` / `required_by`, epochs, and `on_change` hooks.

If you're brand new, read them in that order.
